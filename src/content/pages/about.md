# 👋 Hey, I'm Ahmed

I'm **Ahmed Gamal**, but online you might know me as **Dexter**.

I'm an **IT student, penetration tester, bug bounty hunter, and offensive security enthusiast** based in Egypt.

I spend a lot of my time exploring applications, breaking things in labs, solving CTF challenges, hunting for vulnerabilities, and trying to understand what's happening behind the scenes.

> **Break it. Understand it. Document it.**

---

## 🧑‍💻 What I Do

My main interest is **offensive security** — especially finding the gap between what an application is *supposed to do* and what it *actually allows an attacker to do*.

### 🔥 Web Security

- Web Application Penetration Testing
- API Security Testing
- Authentication & Authorization
- Business Logic Vulnerabilities
- IDOR / Broken Access Control
- XSS, SQL Injection, SSRF & CSRF
- File Upload Vulnerabilities
- Security Misconfigurations

### 🧠 Beyond Web

I'm also constantly exploring different areas of offensive security:

- 🔐 Cryptography
- 🧩 Reverse Engineering
- 💥 Binary Exploitation
- 🪟 Active Directory
- 🐚 Red Teaming
- 📱 Mobile Security
- 🕵️ CTFs & Security Research
